# 市场部文件

先弄清读者和使用场景：管理层决策、销售拜访、客户说明、内部培训和投标附件需要不同细节。沿用用户模板、品牌规范和已确认表述；没有模板时用清晰、可编辑的简单结构，不把某个团队的字体、配色或版式当成普遍标准。

## 按用途组织内容

| 产物 | 建议结构 | 容易写错的地方 |
| --- | --- | --- |
| 产品单页 | 目标使用场景、已证实能力、配置条件、来源 | 把技术指标直接推成临床或商业效果 |
| 竞品对照 | 相同用途与产品层级、同口径参数、证据日期、差异 | 不同配置/市场/版本混比，缺证写成对手没有 |
| 销售问答 | 客户问题、可用答复、适用条件、不能确定部分 | 用绝对保证替代有范围的能力说明 |
| 周月报 | 本期变化、可核事实、影响判断、后续行动 | 重复旧消息，发布时间冒充事件时间 |
| 市场分析报告 | 决策问题、关键发现、证据、建议、限制 | 只有图表没有结论，或建议超出样本覆盖 |
| PPT 汇报 | 一页一个主要信息、图表支持、结论与下一步 | 一页堆满文字，用图片代替可编辑数据图 |

## 从资料到可用文字

把准备写入的事实句与证据 ID 对应。事实、解释和行动建议分开。引用能支持数值，不一定支持“行业领先”“效果更好”等延伸宣传；比较或功效结论需匹配的证据。没有充分依据时换成可证实的具体能力或明确待核。

同一指标在正文、表格、图中使用一致的数值、单位、时期和样本。原始值保留精度，展示单位可换算；图轴、数据标签、脚注和文字一并换算。预算、中标金额、合同价和单台成交价分开描述。

对时效性强的内容写清截至时间，使用本次可核来源。历史证书或旧宣传页不能替代当前官方状态。医疗、法律或财务相关结论应回到相应权威原始来源，不能仅由摘要推断。

## 选图与格式

比较大小用条形图，连续趋势用折线图，构成用少量有意义类别，分布用直方图/箱线图并保留样本量。类别过多时使用排序或分面，别为了图面整齐删掉影响分母的类别。零基线、断轴和对数轴需与读者解释相符。

用户要可编辑图时，用当前环境支持的原生图表和嵌入数据；截图可用作预览，但不是可编辑图表。对透视表、切片器或动画等原生能力，只在检查实际对象后声明已实现。工具不足时交付可编辑表格/结构化图表数据，并明确限制。

## 交付检查

打开或重新解析成品，核对数字、证据编号、图例、来源、页序和可编辑对象。渲染或导出预览检查文字溢出、遮挡、截断、字体替代和打印区域。重点检查关键结论，避免对低风险文字改动做不必要的全套审计。

输出源文件、必要预览和简短说明；不得把内部批注、私人信息或凭据夹入外发件。发送或公开发布按当前明确授权执行，生成文件本身不意味着已发送。
