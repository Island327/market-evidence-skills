# 收到市场表格后怎样分析

分析从问题与有效母集开始，而不是先画图。先读实际工作簿、工作表、表头和几行代表记录，再决定清洗与计算。保留用户原件；任何纠正保留原值、新值、原因和依据。

## 1. 形成可执行口径

至少说明：本次支持什么决策、时间范围、地域、产品范围、数据来源与更新时间、行粒度、金额/数量单位、业务阶段、去重依据、有效样本和未知项。可用 [任务简报](../assets/templates/task-brief.md) 和 [指标字典](../assets/templates/metric-dictionary.csv)。

先确定一行是公告、项目、采购包、标的、合同明细还是报价。不要把多次公告当多次成交；预算、结果、合同和更正可能属于同一生命周期。跨来源合并需有项目/包/标的/阶段关系，不能直接拼接后求和。

## 2. 做影响分析的质量检查

- 核对明细页，排除标题行、空行、小计和总计；筛选或隐藏行是否属于范围按任务确定，不依赖肉眼可见行。
- 检查表头、编码、日期格式、币种、税口径、数量单位、金额是元还是万元，以及单价/总价/包价的层级。
- 检查缺失、非法数值、重复 ID、同项目多行、同记录冲突和异常日期。记录输入行数、保留行数、排除行数与原因，能回到源行。
- 合并单元格只在明确层级关系内向下补值，不跨项目盲填。不要仅凭工作表声明的尺寸判断空表；必要时检查实际单元格。
- Excel 公式是否重算单独核实，缓存可能缺失或陈旧。值副本保留原件与重算来源。宏、外链和嵌入内容不自动执行。
- 结构化产品分类优先于备注关键词。“不属于某产品线”不能因为含有关键词就被算入该产品线。
- 完全相同的来源记录可去重；重复公告、部分相同和同项目不等于重复明细。冲突或低置信候选进入待核台账。

保留一个分析副本和清洗/排除台账，不为一次分析改写权威业务数据库。

## 3. 各指标单独定义有效母集

| 指标 | 常用计算 | 必须声明 |
| --- | --- | --- |
| 观察金额 | 同币种、阶段、计价层级和税口径的有效金额之和 | 有效金额记录数、缺失数、是否为含税值 |
| 观察数量 | 同一可相加单位的有效数量之和 | 单位、缺失数、套/台/模块能否相加 |
| 项目数 | 有效项目键去重计数 | 一项目可跨多品牌/月份，分组数不可直接相加 |
| 样本份额 | 某组有效金额或数量 / 同范围对应有效总量 | 份额类型和覆盖范围，缺品牌归入未知组 |
| 中位单价 | 同型号、配置、单位、阶段、税口径、币种和期间的可比单价中位数 | 单价有效 n、缺失与异常处理、偶数样本取中间两值平均 |
| 同环比 | 同覆盖范围和时间窗口的本期/基期变化 | 完整月与未完月区分，基期为零时不用普通增幅公式 |

金额缺失的记录仍可能用于数量或项目统计；缺失不填零。份额按同一指标有效母集计算，不因某品牌缺失价格而偷偷换分母。金额与数量同时有效的配对子集才可计算加权均价，不能拿所有金额除以另一批记录的数量。

## 4. 从描述到比较

先描述观察样本的规模、时间趋势、地域、产品/品牌结构和覆盖缺口，再看客户/项目、价格分布或机会。根据问题选择维度，不机械输出所有交叉表。

价格先数值筛查，再核对原文业务含义：极低值可能是附件、服务或单模块，极高值可能是整包、配套或录入单位错误。异常值不是错误的证明，不自动删除或套固定阈值。合并/拆分或纠正需有项目与采购包证据，留排除原因和对结果的影响。

区域或品牌均价差可能来自产品组合。先在同型号、配置、单位、税口径、币种、阶段及相近期间内比较。需要整体标准化时定义共同篮子和固定权重，报告双方覆盖率及不重叠部分。没有共同可比样本就不做确定高低排序，不能把不同组合直接排名为价格水平。

用金额、数量、样本量和分布共同解释变化。某组份额变化可能是来源覆盖变动、缺失增加或项目集中，不直接解释成竞争优势。样本覆盖的是已采集市场，不能自动外推全国总量。需要市场规模推算时另建明确假设、范围和不确定性情景。

## 5. 把分析变成建议

每条主要发现带数值、样本量、比较基准、期间与来源。建议说明适用对象、建议动作、支撑证据、仍需确认的条件。把“观察到”“可能解释”和“建议做”分开。描述性数据无法证明价格下降造成销量增长。

所有图表和文案使用同一结果表；统计值、展示值分开。最终报告可用 [分析报告模板](../assets/templates/analysis-report.md)，包含质量摘要、指标口径、主要发现、证据支持的建议、局限和附表。

## 6. 复核与交接

抽查代表行和影响最大的异常，手算小样本验证公式。整体与分组金额/数量应对得上；项目等非加性指标从全体重算。检查分母为零、空样本、缺失品牌和比较组不重叠的情况。

记录输入哈希、工作表/过滤范围、字段映射、方法版本、排除规则、指标样本量及输出哈希。业务表更新后重新冻结版本；不要混用两个时间点的快照和 Excel。需要两种格式时从同一冻结结果导出，核对主键、行数、字段和关键汇总。

生成、校验、发出、接收和成功导入分别记状态。只给接收者真正需要的数据、字段说明和格式说明；“完整”必须说明完整的是哪个来源、时间点和范围。

附带工具提供可复算的基础描述，详见 [脚本说明](analyzer.md)。它不替代原文核查、跨来源去重或业务推断。
