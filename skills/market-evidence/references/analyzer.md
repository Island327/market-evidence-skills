# 可选表格分析工具

`scripts/analyze_table.py` 是只读的基础描述工具，不是清洗服务或业务数据库客户端。运行路径以仓库根目录为例；复制 Skill 后可改成当前文件夹中的相对位置。CSV 仅用 Python 标准库，XLSX 额外需要 openpyxl 3.1.5 或更高的 3.x 版本。Python 最低版本为 3.10。

## 输入契约

UTF-8 CSV 或明确 `--sheet` 的 XLSX；首行是非空且不重复的表头，每行是一个已核定的业务明细。程序读取全部非空行，包括隐藏行；不会按界面筛选状态取子集。已过滤范围请提供独立值副本。不要混入标题、小计和合计。

参考 [合成输入](../assets/examples/market.csv) 和 [配置](../assets/examples/analysis-config.json)。配置映射 15 个规范字段，真实表头可以是中文：

| 字段 | 含义与要求 |
| --- | --- |
| record_id | 当前明细的稳定标识；缺失排除，不能临时编号冒充跨来源去重键 |
| project_id | 稳定项目键；缺失仅不计项目数 |
| date | 明确业务阶段对应日期，YYYY-MM-DD |
| stage | 一次仅分析一个阶段，如 award；预算/合同分开 |
| brand / region | 品牌、地区；空值保留为未知分组，不丢失其已知指标 |
| model / configuration | 单价分层所需精确型号与配置；缺失时仅不计单价 |
| currency / quantity_unit / tax_basis | 本次固定币种、数量单位和税口径 |
| amount_basis | 仅接受已核实的 `line` 明细行金额；包价先另行处理 |
| amount | 行金额，非负，缺失不填零 |
| quantity | 正数；零、负数或缺失不计数量 |
| unit_price | 同币种、税口径、数量单位的明确单价，正数 |

数字接受小数点和正确三位千分位，例如 `1234.50`、`1,234.50`。不猜测小数逗号、货币符号、百分号、万元和科学计数法。先按数据字典明确转换并记录换算。示例税口径、币种和阶段均可改，但不能缺省推断。

若原表缺少某个范围字段，只有已由元数据或用户确认该值对全表成立时，才在分析副本添加常量列并记录依据。未知值不能用常量伪装成已知。如果表格不是这个粒度，按市场分析参考另写针对性计算，不强行套入工具。

## 配置和统计行为

- `scope` 的五项各固定一个值，只有全部相符的记录进入本次分析；不同口径分开运行。
- `start_date`、`end_date` 是含首尾日期的范围。日期格式不明或非法的行排除并登记。
- `group_by` 为 brand、region、model、stage、month 的非空子集，多个维度构成联合分组。空字符串就是未知组，不与真实的“Unknown”品牌混并。
- 同 ID 的规范字段完全相同时保留第一行、登记其余重复；同 ID 有冲突时全部排除待核。这个检查不处理不同 ID 的转载、更正或多来源业务重复。
- 金额、数量、项目分别统计有效 n；某指标无有效值时合计为 null。合法的零金额与空金额有区别；全体合计为零时份额为 null。
- 份额按对应指标的已知合计计算，0 到 1 表示比例；组内无有效值时为 null。缺失金额记录不构成已知的零份额。
- 单价按型号、配置、月份分层；其他比较条件由 scope 固定。输出 n、中位数、最小值和最大值，不输出混合型号总体均价或自动排名。
- `derive_unit_price` 默认应由任务选择；演示为 false。为 true 时，仅空单价且金额与数量有效、行金额大于零才推导单价并登记。已有非法值不会被推导覆盖。
- `price_relative_tolerance` 指金额与单价×数量的相对允许差，不是价格异常阈值。演示为 0.01；请按计价和舍入规则设置。超过阈值时仅排除单价统计，金额/数量仍各自保留；Agent 需从 review.csv 核对冲突是否影响整个交易。商业折扣、配套与服务混入也可能造成差异，不自动改金额。

工具不换汇，不清洗产品分类，不做跨来源事件合并，不认定低价一定异常，不计算总体市场规模，不作因果判断，不生成图表或原生 Office 文件。上述工作按实际任务在结果之上完成。

## 运行

```bash
python3 skills/market-evidence/scripts/analyze_table.py --input skills/market-evidence/assets/examples/market.csv --config skills/market-evidence/assets/examples/analysis-config.json --out outputs/demo
```

XLSX 必须指定工作表。工具读取实际单元格，不只信任文件声明的尺寸；分析字段中若出现公式或 Excel 错误会拒绝本次分析。它不执行宏、外链或公式，不认可未知是否更新的缓存。请在可信表格软件中重算、检查后提供值副本并保留原件。

## 输出

| 文件 | 内容 |
| --- | --- |
| summary.json | 范围、时间、有效母集、指标、分组、单价分层和限制 |
| groups.csv | 联合分组汇总与观察样本份额 |
| price_strata.csv | 可比键内单价分布；是否商业可比仍需核实 |
| review.csv | 源行号、记录键、影响层级、字段和原因；一行可有多条问题 |
| report.md | 基础统计说明；不自动编造业务结论 |
| manifest.json | 输入、配置、脚本与产物 SHA-256，实际参数和生成状态 |

JSON 中十进制指标保存为字符串，避免金额转二进制浮点；null 为未知或无有效样本。后续使用 Decimal 或对应精确数值类型读取。CSV 空白表示未知，输出文本做公式注入转义；JSON 保留原始维度标签。非空输入行的行号是源工作表/CSV 逻辑记录号，不是重新排列后的编号。

输出只写新目录，不覆盖原件和旧结果。manifest 只记录文件名，不记录机器绝对路径；它的生成状态不代表已经人工核验、发送或被接收方导入。产物可能包含输入提供的业务标签/记录键，仍属于用户数据，不能未经授权公开。
