## 市场表格

`market.csv` 模拟已完成业务生命周期核对的明细：9 个输入记录，其中一条预算记录不属于本次中标范围，一条为相同 ID 的完全重复记录。故有效 7 行、排除 2 行。

手工核对：

- 金额有效 6 行，总和为 **8,200 CNY**。
- 数量有效 6 行，总和为 **14 unit**。它与金额有效的 6 行并不是同一批行。
- 去重项目 **6 个**；p001 有两个不同标的记录，不能因此删掉一条。
- 显式单价有效 **6 行**，拆成四个型号/配置/月分层。
- A100 / standard / 2025-01：500 和 600，中位数 **550**。
- A100 / standard / 2025-02：700 和 800，中位数 **750**。r008 缺单价，演示配置不推导。
- A100 / extended / 2025-02：中位数 **600**，不与 standard 合并。
- B200 / standard / 2025-02：中位数 **600**。
- Brand A 金额 **3,800**；Brand B **3,200**；Brand C **1,200**；未知品牌金额为空，数量 **1**。

不能用 8,200 / 14 得到可比均价；不能称这些品牌的观察样本份额为真实全市场份额。不能仅凭跨月份中位数差判断价格上涨，因为样本和交易条件可能变化。
